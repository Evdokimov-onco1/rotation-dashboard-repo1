# Дашборд ротаций ординаторов · ММКЦ «Коммунарка»

Веб-сайт для заведующих-кураторов: кто из ординаторов сейчас на ротации в подразделении,
кто завершил ротацию (пора подписать логбук), кто придёт следующим. Учебный год 2025/26,
ординаторы 1-го года.

## Состав репозитория

| Путь | Что это |
|---|---|
| `docs/TZ.md` | **Техническое задание** — главный документ, по нему ведётся разработка |
| `docs/prototype-demo.html` | Утверждённый кликабельный прототип интерфейса (открыть в браузере, PIN админки: 1234) |
| `data/seed.json` | Исходные данные: недели, подразделения, кураторы, график ротаций (исправленный) |
| `frontend-prototype/` | Исходный код прототипа (React + TypeScript + Tailwind + shadcn/ui) — основа боевого фронтенда |

## Как продолжить разработку в Claude Code

Открыть Claude Code в корне репозитория и дать задание, например:

> Прочитай docs/TZ.md и data/seed.json. Реализуй Этап 1 по ТЗ: создай /frontend на основе
> /frontend-prototype (замени демо-дату на реальную и локальное состояние на работу с API)
> и /backend на PHP 8.2 + SQLite по разделу 7. Хостинг — виртуальный хостинг Timeweb,
> деплой через GitHub Actions (раздел 9). Начни со структуры БД и API, затем подключи фронтенд.

## Запуск прототипа локально (по желанию)

```bash
cd frontend-prototype
npm install
npm run dev
```

Либо просто открыть `docs/prototype-demo.html` в браузере — это тот же прототип одним файлом.

## Целевая архитектура (кратко, детали в ТЗ)

- **frontend/** — React SPA (три экрана: кабинет куратора, матрица-Гант, админка)
- **backend/** — PHP 8.2, REST API, SQLite (файл БД вне webroot)
- Просмотр публичный; редактирование — по PIN
- Уведомления кураторам в Telegram: рабочие дни, 7:00 МСК (этап 2)
- Хостинг: виртуальный хостинг Timeweb, поддомен вида rotation.mmcc-education.ru
