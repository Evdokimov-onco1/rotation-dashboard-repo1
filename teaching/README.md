# Учебная нагрузка · изолированный пилот

Пилотный модуль планирования и учёта нагрузки за 2026/27 учебный год. Адрес предварительного просмотра: `https://rotation.mmcc-education.ru/teaching-preview/`. Вход, PHP API, SQLite, сессии и сборка отделены от приложения ротаций. В рабочее меню ротаций ссылка пока не добавлена.

## Что работает

- Месячный план из исходной структуры XLSX: предварительный просмотр, точное сопоставление преподавателей, сверка сумм и блокировка ошибок. Повторный импорт не дублирует план. Импорт не создаёт факта.
- Отдельные календари лекций и семинаров: черновик, публикация, изменение и отмена с проверкой конфликтов преподавателя, группы и аудитории. Практические занятия учитываются за месяц без календарной даты.
- Факт → отправка → подтверждение либо возврат с комментарием. Преподаватель видит свои записи; учебная часть может вносить за него. Подтверждает отдельная роль `approver`.
- Исправление подтверждённого факта отдельной редакцией, защита от устаревших вкладок, журнал авторов, закрытие месяца и открытие с причиной.
- Расчёт целыми сотыми часа по версии норм, контроль дневного предела аттестаций. Подтверждённый факт выгружается в исходный DOCX-бланк с неизменяемым снимком и контрольной суммой.

Все выгрузки помечены «ПРОЕКТ · ТЕСТОВАЯ ВЕРСИЯ». Подписи не заполняются. Нормы являются настройкой пилота: годовая база и её утверждение требуют отдельного решения до рабочего запуска.

## Структура

| Путь | Назначение |
|---|---|
| `backend/`, `schema/` | Правила расчёта, роли, учёт и хранение |
| `frontend/` | React + TypeScript, адаптивные формы и календари |
| `templates/` | Пустой DOCX-бланк без заполненных персональных данных |
| `public/` | Вход API и правила защиты Apache |
| `scripts/` | Подготовка сборки, первичное создание БД и импорт |
| `tests/` | Синтетические проверки расчёта, учёта, импорта и выгрузки |
| `docs/API.md`, `docs/DEPLOY.md` | Контракт и порядок публикации/отката |
| `.local/`, `.release/` | Игнорируемые рабочие данные и результат сборки |

## Проверка и локальная разработка

PHP 8.2+ с PDO SQLite, DOM, XML, ZipArchive, mbstring; Node 20.19+ или 22.12+; Python 3 для упаковки. Для PHP можно использовать `Dockerfile`.

```bash
cd teaching/frontend
npm ci
npm run build
node tests/metrics.test.mjs
cd ..
php tests/rules_test.php
php tests/workflow_test.php
php tests/report_test.php
php tests/import_test.php
python3 scripts/package.py
```

Для локального сервера задайте `TEACHING_CONFIG` с путём к приватному конфигу (`secure=false` только на localhost), создайте отдельную базу через `scripts/provision.php`, скопируйте `frontend/dist/` в `public/`, затем `php -S 127.0.0.1:8317 dev-router.php`. Пароли/данные готовятся вне Git. Тест HTTP рассчитан на локальный пустой факт и специально подготовленный сид; запускать его на хостинге нельзя.

## Границы первого выпуска

Один учебный год, ручное создание событий и перенос через карточку. Серии, drag-and-drop, рабочее управление аккаунтами, уведомления, SSO, публичное расписание и утверждение норм в интерфейсе — следующий этап. Рабочие доступы преподавателям не выдавались; общие тестовые роли не предназначены для официального подтверждения нагрузки.

Полная продуктовая спецификация, реальные исходники, список преподавателей, протокол приёмки и реквизиты тестового входа хранятся в локальном проекте владельца. Публичный репозиторий содержит код и обезличенные тесты.
